Internal Markdown/HTML links, image paths and Markdown fragments are checked offline
by scripts/verify_reference.py. Local existence and hashes are not a live HTTP test.
Authenticated tenant routes need an authorized account and may be record-specific;
they are evidence/navigation references, not public destinations or clone endpoints.
The clone API contracts are independent proposals in architecture/api-plan.md.

references. They are not known-good readable articles, not evidence of missing
product features, and no alternate private endpoint is supplied.

External sources were inspected selectively at human/research pace, not crawled.
No claim that all external URLs currently return usable content. Public product
updates fill documented behavior while visual/side-effect gaps remain in GAPS.csv.
